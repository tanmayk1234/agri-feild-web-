# Agri Founders Field

**India's only on-farm venture building program** — a joint initiative by [Sahyadri Farms](https://sahyadrifarms.com), [Digital Impact Square (DISQ)](https://disq.co.in), and [Maharashtra State Innovation Society (MSIS)](https://msins.in).

## About

Agri Founders Field is a venture builder that co-creates category-defining agri-ventures with passionate founders. Unlike traditional accelerators, we don't ask you to bring your idea — we provide validated opportunities backed by deep field research, market sizing, and guaranteed pilot customers through Sahyadri's 15,000+ farmer network.

### What Makes Us Different

- **Blueprint to Build** — Validated opportunities with research, roadmap, and resources ready
- **Co-founder Discovery** — Find your team during the residential bootcamp
- **Agri Sandbox** — On-farm co-working with direct access to farmers, R&D labs, and packhouses
- **Practitioner Mentorship** — Learn from operators who've built 2,000+ crore agri-ventures
- **Access to Capital** — Investor network, grants, and catalytic capital through government and CSR partners

## The Venture Blueprint Method

Each venture opportunity goes through rigorous validation:

1. **Deep Field Research** — 1,000+ stakeholder interviews across the value chain
2. **Friction Mapping** — Identifying where value is lost (post-harvest losses, broken logistics, financing gaps)
3. **Opportunity Sizing** — TAM/SAM analysis with unit economics frameworks
4. **Solution Blueprinting** — Detailed blueprint with competitive landscape and risk mitigation
5. **Pilot Guarantee** — 10,000+ trucks of pilot volume, daily dispatch windows, real customers from day one

## Getting Started

1. Clone the repository:
   ```bash
   git clone https://github.com/tanmayk1234/agri-feild-web-.git
   cd agri-feild-web-
   ```

2. Open in browser:
   ```bash
   # Any local server works, e.g.:
   npx serve .
   # or simply open index.html in your browser
   ```

No build step required — the site is static HTML/CSS/JS.
